


**Student-Portal** is a user-friendly and interactive web application developed using **React.js and Vite**. The main purpose of this project is to provide students with a simple platform where they can explore programming courses, view course details, log in to their account, and manage their student information through a dashboard.

The application provides a clean and attractive interface with a **baby pink and brown color theme**, along with a red logout button for easy identification. The portal is designed to be simple, organized, and easy for students to navigate.

The **Home page** provides a welcome section and an option to explore available courses. The **Courses page** displays different programming courses such as **React, JavaScript, Python, and Java**. Students can select a course and view additional information about the course, including topics such as fundamentals, practical coding, projects, advanced concepts, and interview preparation.

The **Login page** provides a simple login form where students can enter their email address and password. After logging in, students are taken to the **Student Dashboard**. The dashboard provides an overview of student information, including enrolled courses, average progress, and assignments.

The portal also includes a **Profile section**, where students can view their basic information such as name, email, course, and academic year. The **Settings section** provides options for enabling email notifications and course reminders. The **Logout feature** allows students to securely leave the dashboard and return to the Home page.

The project uses **React state management and conditional rendering** to control navigation between different sections of the application. It also demonstrates the use of event handling, forms, reusable UI elements, and CSS styling.

## 🔄 Application Flow

The basic flow of the application is:

**Home → Courses → Course Details**

and

**Home → Login → Dashboard → Profile / Settings → Logout → Home**

This flow provides a simple and organized experience for students.

## 🎨 User Interface

The application uses a **baby pink and brown color combination** to create an attractive and comfortable interface. Brown is mainly used for navigation, headings, and buttons, while baby pink is used for backgrounds, borders, and dashboard elements. The Logout button is displayed in red to make the action clearly visible.
